# Labs strategy

Labs are educational features and potential search landing pages. Expansion should stay deliberate: ship one polished lab at a time, connect it to a crawlable explanation, and validate keyboard, touch, reduced-motion, and narrow-screen behavior.

Candidate sequence:

1. Stacking-context visualizer
2. Container-query playground
3. HTTP caching visualizer
4. ARIA pattern playground
5. Core Web Vitals visualizer

The existing Flexbox, Grid, event-loop, and specificity labs remain the interaction baseline. A future standalone lab route should provide an indexable explanation while progressively enhancing into the interactive tool.
